# 2
1) Калькулятор:

- Работает с целыми и дробными числами.
- Поддерживает операции `+`, `-`, `*`, `/`, `//`, `%`.
- Учитывает порядок действий.
- Поддерживает скобки, в том числе вложенные.
- Поддерживает знаки перед числами и скобками: `-2`, `1 + -2`, `-(2 + 3)`.
- Поддерживает несколько унарных знаков перед числами и скобками: `--2`, `-+-3`.
- Позволяет ставить пробелы между числами и знаками.
- Сохраняет успешные вычисления в JSON.

2) Конвертер переводит:

- Длину: `mm`, `cm`, `m`, `km`.
- Массу: `g`, `kg`.
- Температуру: `c`, `f`, `k`.

Регистр единиц не важен: можно писать `kg`, `KG` или `Kg`.

# 3 Установка

В настройках проекта указано требование Python 3.12 или новее.

Команды ниже предназначены для Windows PowerShell.

Скачать репозиторий:

powershell
git clone https://github.com/kuprummm/python-labs.git
cd python-labs


Создать и включить виртуальное окружение:

powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1


Из корня `python-labs` установить зависимости и программу:

powershell
python -m pip install -r lab_01/requirements.txt
python -m pip install -e ./lab_01


Параметр `-e` позволяет изменять Python-код без переустановки после каждой правки.

# 4 Запуск

После установки команды можно выполнять из корня репозитория с включённой `.venv`.

Справка:

powershell
python -m toolkit --help

Вычисление выражения:

powershell
python -m toolkit calc "2 + 3 * 4"

Результат: `14`.

Выражение со скобками и минусом:

powershell
python -m toolkit calc -- "-(2 + 3)"

Результат: `-5`.

Здесь `--` показывает, что дальше идёт выражение, даже если оно начинается с минуса. Выражение с пробелами нужно брать в кавычки.

Выражение с несколькими унарными заками также поддерживается
python -m toolkit calc "23---1"

Результат: `22`.

Перевод граммов в килограммы:

powershell
python -m toolkit convert 1000 --from g --to kg

Результат: `1.0`.

Перевод градусов Цельсия в градусы Фаренгейта:

powershell
python -m toolkit convert 1 --from c --to f

Результат: `33.8`.


# 5 Как работает калькулятор

Вычисление состоит из четырёх шагов:

1. Строка делится на числа, знаки операций и скобки.
2. Проверяется правильность выражения.
3. Выражение переводится в RPN - запись, где операция идёт после чисел. Например, `2 + 3` превращается в `2 3 +`.
4. Результат вычисляется с помощью стека - списка, из которого сначала берётся последний добавленный элемент.

При обработке скобок функция построения RPN вызывает себя для выражения внутри них.

Для чисел используется `Decimal`. Стандартная точность - 28 значащих цифр всего, а не 28 знаков после точки.

# 6 Правила для чисел и операций

В калькуляторе дробная часть записывается через точку:

- `12` и `12.5` - допустимые записи.
- `.5`, `5.`, `1,5` и `1e3` - не поддерживаются.

Умножение нужно писать явно: `2 * (3 + 4)`.

Для `//` и `%` используется правило:

`a = b * q + r`

Здесь `q` - целое частное, а остаток `r`: `0 <= r < |b|`.

При отрицательном делителе это отличается от поведения обычных целых чисел Python.

Конвертер использует `float`. Длина и масса переводятся по коэффициентам из JSON, температура по формулам в коде.

# 7 Ошибки и ограничения

Существующие ошибки:

- Пустое выражение.
- Недопустимые символы.
- Неправильную запись числа.
- Пропущенные числа или знаки операций.
- Два бинарных оператора подряд, например `2 */ 3`.
- Неправильные скобки.
- Деление на ноль через `/`, `//` и `%`.
- Неизвестные единицы измерения.
- Перевод между разными группами величин.
- Температуру ниже абсолютного нуля.

Сообщения об ошибках выводятся в `stderr`.

Коды завершения:

- `0` - успешное выполнение.
- `2` - ошибка пользователя.

В конвертере `nan` и `inf` не поддерживаются.

# 8 История вычислений

Успешные вычисления калькулятора через CLI записываются в `history.json`.

Файл создаётся в папке, из которой запущена команда.

В каждой записи сохраняются выражение и результат.

Пример:

[
    {
        "expression": "1 + 2",
        "result": "3"
    }
]

`conversions.json` входит в репозиторий и устанавливаемый пакет, так как нужен для работы конвертера.
