# 2 Что умеет

- Добавлять и удалять книги.
- Получать книгу по ID.
- Показывать все книги по порядку ID.
- Искать по началу названия и по жанру без учёта регистра букв.
- Сохранять каталог в JSON и загружать его обратно.
- Проверять данные книги и сообщать об ошибках.
- Отменять добавление и удаление книг.
- Читать файлы старого формата.

# 3 Установка

Нужен Python 3.12 или новее. Команды ниже для Windows CMD.
Выполнять их нужно из папки `lab_03`.

Создать и включить окружение:

```cmd
python -m venv .venv
.venv\Scripts\activate
```

Установить наш пакет:

```cmd
python -m pip install -e .
```

Параметр `-e` позволяет менять код без переустановки пакета после каждой правки.
Если установка выполняется из корня `python-labs`, команда будет
`python -m pip install -e ./lab_03`.

Для самой программы дополнительные библиотеки не нужны.
Для тестов и проверки кода установить из папки `lab_03`:

```cmd
python -m pip install -r requirements-tests.txt
```

# 4 Запуск

Для первого запуска скопировать пример в рабочий файл:

```cmd
copy examples\books.json library.json
```

Если `library.json` уже есть, копировать заново не нужно.

После установки пакета запустить программу:

```cmd
python -m library_catalog
```

В новом окне CMD нужно снова включить окружение через `.venv\Scripts\activate`.
Переустанавливать пакет и задавать `PYTHONPATH` не нужно.

Для работы с другим файлом:

```cmd
python -m library_catalog --file другой.json
```

Файл должен существовать. Для пустого каталога можно скопировать `examples\empty.json`.
Если в пути есть пробелы, взять его в кавычки.

После запуска появится `Команда:`. Доступные команды:

| Команда | Что делает |
| --- | --- |
| `list` | Показывает все книги |
| `get` | Спрашивает ID и показывает книгу |
| `add` | Спрашивает поля новой книги и добавляет её |
| `remove` | Спрашивает ID и удаляет книгу |
| `find-name` | Спрашивает начало названия и ищет книги |
| `find-category` | Спрашивает жанр и ищет книги |
| `undo` | Отменяет последнее добавление или удаление |
| `exit` | Завершает работу |

Данные вводятся по одному, когда программа их спрашивает.
После добавления, удаления и отмены каталог сохраняется автоматически.

# 5 Данные книги

У каждой книги шесть полей:

- `id` - уникальный строковый ID экземпляра.
- `title` - название.
- `category` - жанр.
- `year` - год издания.
- `author` - автор.
- `pages` - количество страниц.

Строки не могут быть пустыми или состоять только из пробелов.
Год и страницы должны быть целыми числами больше нуля.
ID вводится вручную. Две книги с одним ID добавить нельзя.
Поля созданной книги менять нельзя.

Поиск по названию проверяет его начало. Например, `ДЮ` найдёт «Дюну», а `юна` - нет.
Поиск по жанру проверяет полное название жанра. Пустой запрос названия находит все книги.

Если файл повреждён, загрузка не меняет прежние книги.
Ошибки выводятся в `stderr`. Ошибка команды не закрывает сессию.
Код завершения `0` означает обычный выход, `2` - ошибку при начальной загрузке.
Неправильные аргументы запуска тоже дают код `2`.

# 6 Файл каталога

Текущий формат - версия 2:

```json
{
    "format_version": 2,
    "books": [
        {
            "id": "001",
            "title": "Дюна",
            "category": "Фантастика",
            "year": 1965,
            "author": "Фрэнк Герберт",
            "pages": 600
        }
    ]
}
```

В версии 1 жанр называется `genre`. При чтении он превращается в `category`.
При следующем сохранении файл записывается в версии 2.
Пример старого файла - `examples/books_v1.json`.

# 7 Бонусы

- **+3: индекс по категории.** Для каждого жанра хранится множество ID книг.
  Добавление, удаление и отмена обновляют и книги, и этот список ID.
- **+3: undo.** Последнее добавление или удаление можно отменить.
  Несколько вызовов отменяют действия по очереди с конца.
- **+2: каталог только для чтения.** Метод `catalog.read_only()` возвращает
  представление, через которое можно смотреть и искать книги, но нельзя добавлять
  и удалять их. Изменения настоящего каталога видны сразу.
- **+2: переход версии 1 в версию 2.** Программа читает оба формата,
  а сохраняет всегда второй.

История отмены хранится только до выхода из программы и не записывается в JSON.
После успешной загрузки файла она очищается. Если история пуста, `undo` сообщает,
что отменять нечего.

# 8 Файлы

- `src/library_catalog/models.py` - книга и проверки её полей.
- `src/library_catalog/catalog.py` - хранение книг, поиск, отмена и просмотр без изменений.
- `src/library_catalog/storage.py` - чтение и запись JSON.
- `src/library_catalog/errors.py` - ошибки программы.
- `src/library_catalog/constants.py` - версии файла и названия полей.
- `src/library_catalog/cli.py` - команды и ввод в терминале.
- `src/library_catalog/main.py` и `__main__.py` - запуск программы.
- `tests/` - тесты.
- `examples/` - готовые JSON для запуска и тестов в том числе файлы с ошибками.
